# 단어 수어 v10: 최신 배 데이터셋 × 시드 5개 실험

v9의 모델 구조·학습 설정을 유지하고 업데이트된 `word_features_belly_signer_split_20261018/landmarks.csv`로 새로 학습했다. S001~S004의 1,629개 중 품질 `exclude` 55개를 제외한 1,574개를 사용했으며, **S005의 15개는 학습·검증·테스트 모두에서 제외**했다. `caution` 등급은 이전 설정대로 포함했다. 입력 60프레임×146특징, 출력 24클래스, 파라미터 56,888개다.

선택한 분할은 80/10/10(학습 1,260·검증 157·테스트 157). 비교의 공정성을 위해 이전 80/10/10 실험의 **테스트 영상 157개를 5개 시드 전체에서 동일하게 고정**했다. 시드 42~46마다 남은 영상의 학습/검증 배분, 모델 초기화와 학습 셔플을 변경했다. 각 후보는 동일한 Adam 학습률 .001, batch 8, 최대 180 epoch, EarlyStopping patience 20, ReduceLROnPlateau factor .5/patience 5, 클래스 가중치를 사용했다. 최저 검증 손실 가중치를 복원해 평가했다.

테스트 정확도 평균은 **89.17%**, 표준편차는 **2.79%p**(5개 시드의 모집단 표준편차), 범위는 **85.99~93.63%**다. 따라서 데이터 분할과 초기화에 따른 변동이 무시할 수준은 아니다. 시드 44가 같은 테스트에서 가장 높은 정확도와 가장 낮은 손실을 기록했으며, 저장된 `seed_44/best.keras`를 새 프로세스에서 재로드해 147/157, loss 0.17235를 재확인했다. `selected_model.json`이 해당 파일과 SHA-256을 지정한다.

**선택: 시드 44를 v10 후보로 지정한다.** 하지만 최고값을 고르는 데 공통 테스트를 반복 사용했으므로 93.63%는 모델 선택 편향이 있는 탐색적 수치다. 시드마다 검증 세트도 달라 검증 값끼리 완전히 같은 표본 비교가 아니다. 촬영자 독립 평가가 아니며, 새 촬영자·기기·브라우저에서 검증한 뒤 배포 여부를 결정해야 한다. 이전 80/10/10 모델의 144/157과도 테스트 3개 차이만 난다. 기존 웹 배포 모델은 바꾸지 않았다.

`best.keras`는 학습용 Keras 모델이며 브라우저가 바로 읽는 TF.js `model.json`/가중치 파일이 아니다. 웹에 배포하기 전 변환 및 입력/라벨 순서·출력 일치 검증이 필요하다.
