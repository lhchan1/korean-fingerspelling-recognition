# 단어 수어 촬영 가이드

이 폴더의 영상은 팀원별 데이터의 구도, 길이, 동작 시작 시점과 수어 표현을 맞추기 위한 참고 자료입니다. 원본 학습 영상 전체는 GitHub에 올리지 않고 클래스별 대표 영상 1개만 공유합니다.

대표 영상은 수행 방법을 확인하는 기준입니다. 모든 영상을 똑같은 위치와 속도로 복제하지 말고, 수어의 의미가 바뀌지 않는 범위에서 자연스러운 개인차를 포함합니다.

## 촬영자 ID

팀원마다 서로 다른 ID를 사용합니다.

```text
기존 촬영자: S001
팀원 1: S002
팀원 2: S003
팀원 3: S004
```

ID를 중복 사용하면 촬영자 기준 학습·평가 분리가 불가능해집니다.

## 실행

프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
source .venv/bin/activate
python word_sign/capture_words.py --signer S002 --duration 4
```

`S002`는 본인의 촬영자 ID로 바꿉니다.

조작키는 다음과 같습니다.

- `Space`: 3초 카운트다운 후 촬영
- `N`, `Enter`, `→`: 다음 클래스
- `P`, `←`: 이전 클래스
- `R`: 직전에 저장한 영상을 제외하고 다시 촬영
- `Q`, `Esc`: 종료

## 공통 촬영 규칙

- 영상은 1280×720, 30FPS, 4초로 저장합니다.
- 카메라를 정면에 두고 양쪽 어깨와 팔꿈치가 보이게 촬영합니다.
- 사용하는 손이 화면 밖으로 나가지 않게 합니다.
- 한 영상에는 해당 수어를 한 번만 수행합니다.
- 수어를 인위적으로 느리게 늘이지 않고 평소 속도로 수행합니다.
- 미리보기만 거울처럼 보이며 저장 영상은 반전되지 않는 것이 정상입니다.
- 역광과 지나치게 어두운 장소를 피하고 손과 옷·배경이 구분되게 합니다.
- 같은 클래스 안에서도 손의 시작 위치, 카메라와의 거리, 동작 속도에 작은 변화를 줍니다.
- 잘못 수행했거나 화면 밖으로 나간 영상은 즉시 `R`로 제외합니다.

## 4초 영상의 권장 흐름

```text
0.0~0.5초  자연스러운 준비 자세
0.5~2.5초  해당 수어를 한 번 수행
2.5~4.0초  동작을 마치고 자연스럽게 대기
```

동작이 짧으면 억지로 2초를 채우지 않습니다. 대신 카운트다운 직후 너무 늦게 시작하지 않고 수어의 시작부터 끝까지 영상 안에 포함합니다.

## 클래스별 주의사항

### 00 IDLE

특정 수어를 하지 않고 4초 동안 자연스럽게 대기합니다. 모든 영상을 완전히 같은 자세로 찍지 말고 다음 상태를 적당히 나눠서 촬영합니다.

- 손을 편하게 내린 상태
- 손을 배나 가슴 부근에 둔 준비 상태
- 자세를 조금 바꾸지만 의미 있는 손동작은 하지 않는 상태

### 01 OTHER

`나`, `가다`, `학교`, `먹다`, `아프다`가 아닌 행동을 촬영합니다. 대표 영상의 동작을 반복하는 클래스가 아닙니다. 한 촬영자가 10개를 찍는다면 가능한 한 서로 다른 행동을 사용합니다.

- 손 흔들기
- 얼굴이나 머리 만지기
- 옷 정리하기
- 물건 집기
- 의미 없는 손동작
- 현재 학습 대상이 아닌 다른 수어 또는 지문자

### 02~06 단어 클래스

대표 영상에서 손 모양, 방향, 이동 경로와 신체 접촉 위치를 확인한 뒤 자연스럽게 한 번 수행합니다. 단어마다 10개를 촬영하되 10개 모두 같은 속도와 시작 위치로 복사하지 않습니다.

## 촬영 권장 수량

팀원 1명 기준 권장 수량입니다.

| 클래스 | 권장 수량 |

## 촬영 완료 후 전달

촬영을 마치면 본인의 폴더와 `metadata.csv`를 함께 전달합니다.

```text
word_sign/word_dataset/S002/
word_sign/word_dataset/metadata.csv
```

영상, 폴더 및 파일 이름을 직접 변경하지 않습니다. 여러 팀원의 `metadata.csv`는 파일을 단순히 덮어쓰지 않고 병합해야 합니다.

## 제출 전 확인표

- 촬영자 ID가 다른 팀원과 겹치지 않는가?
- 각 영상이 약 4초인가?
- 양쪽 어깨와 팔꿈치가 화면에 보이는가?
- 손이 화면 밖으로 잘리지 않았는가?
- 한 영상에서 수어를 한 번만 수행했는가?
- 잘못 촬영한 영상을 `R`로 제외했는가?
- `OTHER`가 서로 다른 행동으로 구성됐는가?
- 파일명과 폴더명을 직접 바꾸지 않았는가?
